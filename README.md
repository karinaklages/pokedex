<h1 align="left">Pokédex</h1>

###

<p align="left">In this project, a Pokémon trainer registry was developed based on the official PokéAPI. The goal was to make systems and data retrieval compatible. I was free to choose the design, but certain technical specifications had to be met.
<br><br>

Pokédex is part of the Developer Akademie's training programme for software developers (www.developerakademie.com).
